# Old liz-lovelace.com (SvelteKit, 2023–2026)

A snapshot of the site as it was before the October 2026 redesign, copied unchanged
from commit ef26beb. Nothing builds or serves it right now; it's kept so the old
version can be shown exactly as it was later on (see LATER.md in the repo root).

To run it as it was: `npm install && npm run build && node build/index.js` in this
folder (it was built on Node 16).
